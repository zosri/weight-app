# Βάρος και ενέργεια

Εφαρμογή παρακολούθησης βάρους με εκτίμηση θερμιδικής πρόσληψης.
PWA — εγκαθίσταται στην αρχική οθόνη του Android και ενημερώνεται
αυτόματα σε κάθε push από το PC.

---

## Φάση 1 — τι υπάρχει ήδη

- Εισαγωγή βάρους· ημερομηνία και ώρα από το σύστημα
- Αυτόματος χαρακτηρισμός πρωί / βράδυ ανάλογα με την ώρα
- Γραμμή τάσης (EWMA, α=0.1) πάνω στις ακατέργαστες μετρήσεις
- Ενεργειακό ισοζύγιο και TDEE
- Επιλογή διαστήματος, προεπιλογή 30 ημέρες
- Τοπική αποθήκευση και εξαγωγή αντιγράφου ασφαλείας

---

## Στήσιμο, βήμα βήμα

**1. Εγκατέστησε το Node.js** από nodejs.org — την έκδοση LTS.
Άνοιξε ένα terminal και γράψε `node -v`. Αν δεις αριθμό έκδοσης, όλα καλά.

**2. Τοπική δοκιμή.** Μέσα στον φάκελο του project:

    npm install
    npm run dev

Άνοιξε τη διεύθυνση που τυπώνει (συνήθως http://localhost:5173).
Το `npm install` χρειάζεται μόνο την πρώτη φορά.

**3. Φτιάξε repository στο GitHub.** Δημόσιο, με όνομα `weight-app`.
Αν διαλέξεις άλλο όνομα, άλλαξε τη μεταβλητή `REPO` στο `vite.config.js` —
αλλιώς η σελίδα θα φορτώνει λευκή.

**4. Ανέβασε τον κώδικα:**

    git init
    git add .
    git commit -m "Φάση 1"
    git branch -M main
    git remote add origin https://github.com/ΟΝΟΜΑ_ΣΟΥ/weight-app.git
    git push -u origin main

**5. Ενεργοποίησε το GitHub Pages.** Στο repository:
Settings → Pages → Source → διάλεξε **GitHub Actions**.
Το πρώτο build τρέχει μόνο του σε 1-2 λεπτά. Η διεύθυνση θα είναι
`https://ΟΝΟΜΑ_ΣΟΥ.github.io/weight-app/`

**6. Εγκατάσταση στο κινητό.** Άνοιξε τη διεύθυνση στο Chrome →
μενού → «Προσθήκη στην αρχική οθόνη».

Από εδώ και πέρα, κάθε `git push` φτάνει στο κινητό μόνο του.
Δεν ξαναχρειάζεται τίποτα άλλο.

## Δομή

    src/
      tokens.js              χρώματα και γραμματοσειρά
      lib/
        metabolism.js        BMR, TDEE, θερμίδες ανά βήμα
        trend.js             EWMA, κλίση, μετατροπή σε θερμίδες
        date.js              ημέρα, ώρα, πρωί/βράδυ
        storage.js           αποθήκευση, εξαγωγή, εισαγωγή
      components/
        WeightEntry.jsx      φόρμα καταχώρησης
        StatBar.jsx          μπάρα με τα τρία νούμερα
        TrendChart.jsx       γράφημα βάρους
        MeasurementList.jsx  λίστα μετρήσεων
      App.jsx                τα συνδέει όλα
      main.jsx               σημείο εκκίνησης

Οι υπολογισμοί ζουν αποκλειστικά στο `lib/`. Τα components δεν κάνουν
μαθηματικά — έτσι μπορείς να ελέγξεις τη λογική χωρίς να ανοίξεις UI:

    node --input-type=module -e "import {bmr} from './src/lib/metabolism.js'; console.log(bmr({weight:90.5,height:165,age:44,sex:'m'}))"

## Επόμενες φάσεις

**Φάση 2 — βήματα.** Σήμερα το `profile.steps` είναι σταθερό στα 3000.
Πρώτα οθόνη ρυθμίσεων για χειροκίνητη τιμή, μετά Capacitor για Health Connect.

Το κόλπο με το Capacitor: στο `capacitor.config.json` βάζεις
`server.url` τη διεύθυνση του GitHub Pages. Το APK γίνεται κέλυφος που
δίνει native πρόσβαση στα βήματα, ενώ το περιεχόμενο συνεχίζει να
ενημερώνεται από τα push σου. Εγκαθιστάς μία φορά.

**Φάση 3 — εκτίμηση πρόσληψης.**

Προσοχή σε ένα πραγματικό πρόβλημα που εντοπίστηκε στους ελέγχους:
η κλίση του EWMA υποεκτιμά σοβαρά την απώλεια στην αρχή. Σε δοκιμή με
πραγματική απώλεια 0.070 kg/ημέρα:

    21 ημέρες  →  -0.030   (57% απόκλιση)
    40 ημέρες  →  -0.065
    60 ημέρες  →  -0.065

Είναι το startup transient του φίλτρου. Η διόρθωση είναι η ίδια που
χρησιμοποιεί ο Adam optimizer — διαίρεση με `1 - (1-α)^n`, όπου n ο
αριθμός μετρήσεων. Εφάρμοσέ την πριν υπολογίσεις κλίση, αλλιώς η
εκτίμηση πρόσληψης θα βγάζει σταθερά 200-400 kcal παραπάνω τον πρώτο μήνα.

**Φάση 4 — ερωτήσεις μετά το ζύγισμα.**
Το πεδίο `refersTo` υπάρχει ήδη στο σχήμα και πρέπει να δείχνει στο
**χθες**, όχι στη μέρα καταχώρησης. Το `previousDayKey()` στο `date.js`
είναι εκεί γι' αυτόν τον λόγο.

**Φάση 5 — γράφημα διαφοράς πρωί/βράδυ.**

## Αντίγραφα ασφαλείας

Τα δεδομένα ζουν μόνο στο κινητό. Καθαρισμός δεδομένων περιήγησης τα σβήνει.
Το κουμπί εξαγωγής κατεβάζει αρχείο JSON — κράτα ένα κάθε τόσο.
Το `importJSON()` στο `storage.js` το διαβάζει πίσω, αλλά δεν έχει ακόμη
κουμπί στο UI.
